  • Method: WebSearch was exhausted for the session, so every claim was checked by WebFetch-ing the page the chapter cites, or the obvious reference page for it (Wikipedia, USML, the Cabrini shrines, Vatican News, the Indiana State Library blog, OrthodoxWiki, NCSE, themetrains, the Encyclopedia of Cleveland History, America magazine, the Daily Beast piece, the cathedral's own history page), and reading the extract. ~70 pages fetched. Google Books' API rate-limited me (429) and loc.gov blocks page OCR for this fetcher (403), which is why two dates below stay open.
  • Verdict key: CONFIRMED = the cited/reference page states it. CORRECTED = a page contradicts the detail; right fact given. WRONG = the claim is false as written. UNSUPPORTED = no page I could reach states it (it may still be true). A handful of low-risk items were not checked and are listed separately so the counts stay honest.
